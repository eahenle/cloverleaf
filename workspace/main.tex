\section{A focused authoring loop}

Like a double rainbow all the way across the sky, Cloverleaf brings the project tree, source editor, compiled document, and manuscript assistant into one view. Saving and compilation happen independently, so a quick sequence of edits is coalesced into a final build without overlapping compiler processes.

\section{Local by design}

Project files remain on this machine. The backend validates workspace paths, invokes the compiler without a shell, and keeps provider credentials out of browser requests. The example is intentionally long enough to exercise multipage preview behavior.
